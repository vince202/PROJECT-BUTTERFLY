# Crédits — modèles 3D

Les modèles glTF de `public/models/kenney/` proviennent des packs de **Kenney** (www.kenney.nl), publiés sous licence **CC0 1.0** (domaine public : utilisation libre, y compris commerciale, sans attribution obligatoire ; merci à Kenney, don volontaire encouragé).

| Dossier | Pack d'origine |
|---|---|
| `nature/` | Nature Kit |
| `roads/` | City Kit (Roads) |
| `cars/` | Car Kit |
| `characters/` | Mini Characters |
| `suburban/` | City Kit (Suburban) 2.0 |
| `commercial/` | City Kit (Commercial) 2.1 |

Tout le reste de la ville (bâtiments du quartier central, mobilier, personnages procéduraux) est généré par le code du projet.

Les modèles de `public/models/quaternius/` proviennent des packs de **Quaternius** (quaternius.com), publiés sous licence **CC0 1.0**, récupérés via leurs miroirs OpenGameArt et convertis d'OBJ en glTF binaire avec `obj2gltf` :

| Dossier | Pack d'origine |
|---|---|
| `medieval/` | Medieval Village Pack (déc. 2020) : maisons à colombages, auberge, clocher, moulin, étals de marché, puits, kiosque, bancs, charrette… |
| `buildings/` | Buildings Pack : maisons, boutique, banque, hôpital, immeubles |
| `street/` | Street Pack : lampadaires, panneaux, feu |
| `characters/` | Ultimate Animated Character Pack (nov. 2019) : personnages animés (marche, course, repos, assis…), convertis de FBX en glTF avec FBX2glTF |
| `transport/` | Public Transport Pack : bus, taxi, vélos, feu, panneaux, ambulance (OBJ → glTF) |
| `props/` | Fantasy Props MegaKit (édition standard) : bancs, chaises, tables, tonneaux, caisses, étals, lanternes, livres (glTF → GLB avec gltf-pipeline) |

`public/models/hdri/dusseldorf_bridge_1k.hdr` provient de **Poly Haven** (polyhaven.com), licence **CC0**, utilisé pour l'éclairage d'environnement.
